Scratch Coding for Beginners

Introduces young learners to programming through Scratch — a simple, visual, and engaging way of exploring coding. Students snap together colourful blocks to build stories, games, and animations, learning core programming concepts without needing to type a single line of code. It's the first step on our coding path, which continues below with Python, web development, Raspberry Pi, and Arduino.
